# Typography

The brand uses one typeface, Plus Jakarta Sans (400, 500, 600, 700), in two roles and an eight-step scale. The `part-b` theme sets them to Fraunces (headings) over Inter (text) and resizes the steps to match the buy box. Size, line height, weight and letter spacing travel together in each step.

## Family

`font-sans` is for text. `font-heading` is for titles and section headings, so `h1` and `h2` use it. The brand sets both to Plus Jakarta Sans; `part-b` sets them to different families without touching a component. Pick a theme in the Storybook toolbar to see its fonts.

## Scale

Tailwind's default sizes are removed: only `text-title`, `text-section`, `text-body`, `text-small`, `text-eyebrow`, `text-caption`, `text-fine` and `text-micro` exist. Values are read from the live tokens.

## Use when

- `text-title`: the page `h1`.
- `text-section`: card and section headings.
- `text-body`: default text and buttons (weight 600).
- `text-small`: secondary info and fine print.
- `text-eyebrow`: short uppercase labels above a heading.
- `text-caption`: compact labels next to an icon, such as trust badges.
- `text-fine`: legal and renewal fine print.
- `text-micro`: the uppercase text inside a small pill badge.
- Prices and any figures that line up: add `tabular-nums` so digits keep the same width.

## Don't use when

- You need a size that isn't in the scale: pick the nearest step instead of `text-[18px]`.
- Choosing a heading level for its look: keep the outline right and change the look with the utility.

## Accessibility

- Brand body text is 15px (16px in `part-b`) with a 1.5 line height; no step is below 11px, and only the uppercase eyebrow is that small.
- Heading level and size are independent: choose the level for the outline, the size for the look.
- Text colors come from tokens whose contrast is tested per theme.

## Do / Don't

| Do                                  | Don't                          |
| ----------------------------------- | ------------------------------ |
| `font-heading text-title` on the h1 | `text-[28px]`                  |
| `tabular-nums` on a price           | A price in proportional digits |
| `text-small text-muted` for hints   | `text-eyebrow` for a sentence  |

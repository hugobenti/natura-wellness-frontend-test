# ResponsiveDialog

A native `dialog` opened as a modal. On a phone it is a bottom sheet; from `sm` up it is a centered modal.

<Canvas of={Stories.Confirmation} />

## When to use it

Use it only for confirmations and short multi-step flows. Anything longer or that needs its own URL belongs on a page.

## Footer order

Put the safe choice first (Keep it), the consequential one after (Skip shipment). On a phone the buttons stack in that order; from `sm` they sit in a row at the end.

## Behavior

- The parent owns `open`. Escape, the close button and the browser's own close all call `onClose`; the dialog closes when the parent sets `open` to `false`.
- The browser traps focus and makes the page behind inert, and returns focus to the button that opened the dialog.

## Accessibility

- `aria-labelledby` points at the title; `aria-describedby` at the description when there is one.
- The close button has a name from the `closeLabel` copy.
